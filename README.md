# StackBP

Proyecto personal de desarrollo web — sitios modernos y funcionales para emprendedores y negocios que buscan presencia online clara y confiable.

## Tecnologías

| Capa | Stack |
|------|-------|
| Frontend | React 19, TypeScript 5.9, Tailwind CSS v4, React Router 7 |
| Build | Vite 8 |
| Iconos | lucide-react, react-icons |
| UI | shadcn/ui (Radix primitives) |

## Requisitos

- Node.js 22+
- pnpm 11

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```
